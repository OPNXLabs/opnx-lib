# Security Policy

[Korean](SECURITY.ko.md)

OPNX.Lib is preview software under active development. Only the latest published preview version is considered for security fixes.

Do not report suspected vulnerabilities through public GitHub issues, discussions, or pull requests. Report them privately to `opnx@opnx.kr` with:

- the affected package and version;
- a description of the vulnerability and potential impact;
- reproducible steps or a minimal proof of concept;
- any known mitigations; and
- a safe contact method for follow-up.

Do not include credentials, personal information, customer data, or production secrets. Allow OPNX reasonable time to investigate and prepare a fix before public disclosure.

Receipt of a report does not guarantee a fix, response time, bounty, compensation, or eligibility for any reward. Commercial support and response commitments require a separate written agreement.
